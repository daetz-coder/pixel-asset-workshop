# 蓝队六兵种 · 5 秒 480p 视频提示词

视频设置选 **5 秒、480p、横屏 16:9**。每次只复制一个代码块。前三条上传同一张[六兵种参考图](blue-units-3x2-reference.png)作为首帧。第四条上传[纯洋红特效底板](blue-units-3x2-fx-reference.png)作为首帧。

| A | 六兵种待机循环 |
| B | 六兵种原地步行循环 |
| C | 六兵种各一次攻击或技能，包含脱手或出弩的关键帧 |
| D | 六种独立特效，按游戏事件叠加 |

## A · 待机循环

```text
用输入图作为首帧，生成一段 5 秒、横屏 16:9、480p 的 2D 像素游戏角色待机动画。固定正交机位、轻俯视四分之三视角、纯洋红 #FF00FF 底色。全片保持首帧的三列两行排版、角色大小、朝右方向、头盔、服装和装备。每格只画参考图里的那一名角色，四周保留洋红空边。双脚始终钉在首帧脚位。保留两条分开的深蓝黑短脚、浅金小手和硬边方形像素。画面仅包含六个角色及装备和纯色底。

0–2.5 秒完成一个平稳呼吸循环，2.5–5 秒重复同一循环。每次循环从首帧姿势出发，上身微微下沉，缓慢回升到相同姿势。循环接缝两端的位置、装备角度和运动速度自然衔接。头盔和道具保持硬质轮廓。每格的细微变化如下。

左上战锤兵，肩和握柄手轻沉，双面锤随手微降再回升。
中上投弹兵，持弹手随胸口小幅起伏，圆铁弹始终托在腰前，引信保持熄灭。
右上旗手，旗杆竖直且下端稳定，只有燕尾旗末端轻轻摆动一下。
左下战斧兵，握柄手轻收又松回，月牙斧头保持原有轮廓。
中下弩兵，两只手始终扶着低位短弩，弩托随呼吸轻微起伏。
右下塔盾兵，盾沿随呼吸轻沉后复位，塔盾始终在身侧。

全程只有待机。采用清楚的离散像素姿势，背景保持完全平坦。禁用运镜、走步、攻击、投射物、特效、地面、阴影、文字和运动模糊。
```

## B · 步行循环

```text
用输入图作为首帧，生成一段 5 秒、横屏 16:9、480p 的 2D 像素游戏角色步行循环。固定正交机位、轻俯视四分之三视角、纯洋红 #FF00FF 底色。保持首帧三列两行构图、各角色原有缩放、朝右方向、头盔、服装和装备。每格的躯干中心围绕首帧位置起伏，地面基准线取首帧脚底高度。六名角色各自在原格内做向右行走的原地步态，镜头与角色根位置锁定。

每秒完成一个左右双步循环，共五轮。首帧为同一循环的双脚近中立过渡姿势。从双脚近中立开始，近脚小步向右前方落地，远脚抬起并从身体下方经过，远脚再向右前方落地，近脚经过，回到相同相位。支撑脚接触同一脚底线，每次都有一脚支撑身体。让双脚交替前后错开，始终是两条短小的深蓝黑像素线，关键步态里两脚之间留出背景空隙。上身只小幅起伏，帽子、躯干、手和装备的比例稳定。第一轮与后续各轮保持同一节拍与步幅，循环接缝平顺。

左上战锤兵，步子沉稳，举着短锤，锤头随落脚轻轻起伏。
中上投弹兵，空闲手小幅前后摆，持弹手把一颗铁弹稳稳贴在腰侧。
右上旗手，旗杆大致竖直，燕尾短旗随步伐向后轻摆。
左下战斧兵，肩和持斧手随步态小幅摆动，斧刃保持在右侧。
中下弩兵，双手低持短弩，前臂随交替落脚轻微起伏。
右下塔盾兵，步幅最短，塔盾随每次落脚轻沉，两条短脚始终从盾下或盾侧露出。

步伐清晰可读，所有脚、手和道具都完整留在原格里。画面只有六名角色和纯色底。禁用原地蹦跳、跑步腾空、单脚滑行、角色横移、运镜、特效、地面、阴影、文字和运动模糊。
```

## C · 攻击与技能

```text
用输入图作为首帧，生成一段 5 秒、横屏 16:9、480p 的 2D 像素游戏战斗动画。固定正交机位、轻俯视四分之三视角、纯洋红 #FF00FF 底色。锁定原图的三列两行排版、原有缩放、角色身份和朝右方向。三列边界在画面宽度的 1/3 与 2/3，两行边界在画面高度的 1/2。每格以首帧两脚之间的地面点为根锚点，重心可小幅倾斜，支撑脚留在原位。保留原图头身比例、硬边方形像素、浅金小手和两条深蓝黑短脚。

0–0.35 秒是原图准备姿势。每格按下面的时间独立做一次动作，在 3 秒前恢复稳定的结束姿势，保持至视频结束。用不同的起势、发力方向和结束轮廓区分六个职业。

左上 · 战锤兵，头顶竖砸。0.35–1.10 秒屈膝，举双面锤到盔顶上方。约 1.25 秒沿近乎竖直的路径向右下砸，锤头最低点与脚底线等高，锤柄斜向下。锤头低位停约 0.10 秒，再短促反弹并抬回原位。清楚显示头顶高点、脚边触地点和回弹。
中上 · 投弹兵，单手过肩抛投。0.35–0.80 秒把一颗铁弹收到右肩后，身体略后仰。约 0.90 秒持弹手越过肩膀向右前上方伸出，松手放出一颗圆铁弹。铁弹在本格内做一小段抛物线，至少有一帧与手完全分离、四周全是洋红。铁弹的可见轨迹在本格右侧留白内结束，始终远离分格边界。手臂完成随挥并收回，结束时双手空着。
右上 · 旗手，垂直举旗号令。0.60–1.50 秒将原有旗杆沿竖直方向推高，旗杆与旗尖完整入画。约 1.60 秒旗面横向展开，燕尾和菱形标记清晰，举旗停留约 0.35 秒，随后垂直落回原位。
左下 · 战斧兵，腰高横扫。0.35–0.65 秒把月牙斧横收至身侧，肩微微反拧。约 0.75 秒从身侧沿腰高水平弧线向右扫过，斧刃一路高于膝脚，斧柄和前臂在末端横向伸展。顺势扭回身体、收斧。斧刃全程保留单侧月牙轮廓。
中下 · 弩兵，平射。0.35–1.10 秒双手抬弩，将弩托抵稳，弩尖朝右，短暂停稳瞄准。约 1.20 秒弩弦弹回，从弩的正前方平直射出一支短弩矢，双手和上身轻微后坐。弩矢至少有一帧与弩完全分离，四周全是洋红。弩矢的可见轨迹在本格右侧留白内结束，始终远离分格边界。随后将空弩放回低位。
右下 · 塔盾兵，受击格挡。0.55–1.15 秒下沉稳住双脚，举盾把盾面翻向右前方，遮住躯干的右半部。约 1.45 秒盾沿受力朝左回弹一小格像素，肩随盾短促后压，双脚保持着地。持盾稳住约 0.35 秒，再将盾落回身侧。

画面只保留六个角色、原有装备和上面明确描述的单颗铁弹、单支弩矢。武器、旗、盾和投射物的完整轮廓始终在原格，四周留出洋红空边。攻击中的冲击由姿势体现。禁用尘土、刀光、爆炸、魔法、受击目标、文字、阴影、运镜、运动模糊和重影。
```

## D · 独立特效

```text
用纯洋红输入图作为首帧，生成一段 5 秒、横屏 16:9、480p 的 2D 像素游戏特效板。固定正交画面，背景始终是均匀的纯洋红 #FF00FF。将画面分成不可见的三列两行，各格的几何中心为特效原点。每格只出现一个特效，各播放一次。每个特效的最宽、最高范围都不超过输出画面的 80 像素，周围保留大量纯洋红空白。所有形状由少量边缘清晰的硬像素色块组成，使用下面指定的颜色。画面只显示特效和纯色底。

0–0.5 秒全空。以下时间分别是特效出现的时刻与持续时间。每个特效在结束后完全回到纯洋红，4 秒以后六格全空。

左上 · 锤击触地。约 0.70 秒出现，持续约 0.35 秒。原点闪出一小块米白接触点，浅灰褐尘团贴脚底线向左右低矮摊开，少量方形尘粒散去。形状宽而扁。
中上 · 铁弹落点爆裂。约 1.10 秒出现，持续约 0.55 秒。原点先跳出亮米黄小核心，短促向外扩为橙黄不规则像素火团，再变成几块深蓝灰烟并消散。形状先聚后散。
右上 · 旗手号令。约 1.45 秒出现，持续约 0.65 秒。一道薄荷青扁椭圆从原点向外张开，三枚短小青白像素向上浮起，圆环和像素块依次消失。形状贴地、展开均匀。
左下 · 斧刃横扫。约 1.90 秒出现，持续约 0.25 秒。浅薄荷和米白组成一条细长月牙，从左向右掠过原点。月牙前缘亮，尾端分成两三块短像素迅速消失。形状窄而横长。
中下 · 弩矢命中。约 2.30 秒出现，持续约 0.25 秒。原点闪出一小簇硬边米白尖屑，三四颗淡青粒子沿射线向右飞散，随即消失。形状细小、方向明确。
右下 · 塔盾挡击。约 2.70 秒出现，持续约 0.30 秒。原点出现一颗冷白闪点，三四道短促金色硬像素火星向右上反弹，迅速收掉。形状小而紧凑。

使用清晰的出现、峰值和消散三段姿势。以像素块缩小、减少和消失表现收尾。禁用角色、武器、投射物、地面、格线、文字、镜头抖动、透明渐变、泛光、模糊和洋红色粒子。
```

## 拆帧和游戏挂点

- 将视频实际宽度的 1/3、2/3 和实际高度的 1/2 四舍五入为分格边界。以实测的 854 × 480 为例，列边界为 `0、285、569、854`，行边界为 `0、240、480`。角色根锚点横坐标为 `127、412、696`，上下排纵坐标为 `166、406`。换算其他尺寸时，锚点横纵坐标分别乘以 `W/854` 与 `H/480`，再四舍五入。
- 待机和步行各取一轮相位连续的循环，去掉重复的接缝帧。步行先确认近脚落地、远脚经过、远脚落地、近脚经过都齐全。角色脚底使用同一画布锚点，游戏中由移动逻辑提供位移。
- 攻击按源帧挑选蓄力、发力、接触或脱手、随动和恢复。约 10 fps 可用于第一轮预览。短暂脱手和出弩姿势先在原帧率下确认，片尾停住的重复帧可裁掉。投弹兵结束为空手，下一颗弹应在独立的取弹或装填动作中出现。
- 铁弹和弩矢从与身体完全分离的帧抠出，角色序列里将这两个独立物件移出。游戏在脱手点或弩口生成投射物，轨迹与命中由游戏控制。
- 特效各自裁切，保留出现、峰值和消散三段姿势，并记录各自原点。锤击尘挂在锤头触地点，斧光随挥斧关键帧挂到刃口扫过的位置。铁弹爆裂和弩矢火星在实际命中点触发。号令环在旗面展开时挂到旗手脚下，格挡火星在受击时挂到盾面接触点。特效板的时间仅用于取帧。

## 旧片复核

源片为 [3 秒试片](e28543c8c1b84af9bdff6d52be9ae371.mp4)，实测 854 × 480、30 fps，共 90 帧。用本地蓝队 Warrior 的 Idle、Run、Attack、Guard，Archer 的 Shoot、Arrow，以及 Monk 的 Heal_Effect 做姿态和特效分层参考。步行采用较慢的左右交替支撑节奏。

| 观察 | 对拆帧与动作读感的影响 |
| --- | --- |
| 片头和片尾近似静止，缺少完整呼吸循环和左右交替落脚。 | 这段片只提供部分战斗动作，无法直接裁出待机和步行。 |
| 约 1.33–1.80 秒，战锤和战斧都在身体前方横向伸直。锤头没有清楚落到脚底线，二者的前伸姿势和停顿近似。 | 用锤头由盔顶到脚边的落差，和斧刃沿腰高横扫的路径，分别标记两种近战。 |
| 约 1.60 秒，铁弹落到右下格的塔盾兵头顶，弩矢已越过中下格右边界。约 1.80 秒，弩矢飞到塔盾右边。 | 按格切片会截断投射物，甚至把铁弹抠进塔盾兵素材。 |
| 旗杆先斜到头盔后方，再向右倾伸。塔盾前后的持盾姿势接近，且没有清楚的接触反馈。战锤和战斧发力时，短脚由竖直变成斜线，脚间距也改变。 | 旗手需要清楚的竖直举旗和展开停顿。盾手需要可辨的遮挡、受力回弹和稳定支撑脚。 |
| 约 2.00 秒投弹兵恢复持弹，片中看不到明确取弹过程。旧提示也将爆炸、烟尘和额外粒子排除在画面之外。 | 结束帧使用空手姿势。接触类特效另取素材，在实际游戏事件发生时播放。 |
| 左上角底色从首帧 RGB `(237, 19, 229)` 变为末帧的 `(226, 19, 222)`，均偏离输入的 `#FF00FF`。右下格还有贴近盾兵脚底的“AI生成”标记。 | 复查底色均匀度、压缩后的轮廓和抠像残边，按实测底色取样。优先使用可导出干净素材画幅的输出设置。 |
