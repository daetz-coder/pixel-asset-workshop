# 各类资产的制作与验收

[English](asset-families.en.md)

每类用同类型贴图学结构，用场景图学相对尺度。档案里把共享规则、类别固定项和本次可变项写开。表中验收点按实际交付使用。

| 类别 | 参考与规格 | 验收 |
| --- | --- | --- |
| 友方兵种、人形敌军 | 同职业或同阵营的 Idle 帧、阵营对照、单位与建筑同屏图。记录朝向、主体高度、脚底、角色和武器范围、阵营色的位置。见 [角色精灵流程](character-sprites.md)。 | 目标尺寸下辨认敌我、职业与武器，脚底和相对身高稳定。 |
| 怪物、首领 | 同类体型、移动方式与攻击轮廓的敌怪原帧或公开预览。先定威胁尺度、主体形状、弱点与攻击部位，再选物种色板、姿态和装备。 | 小尺寸看剪影，和友方单位同屏核对大小及敌我区分。动画需求检查起手和命中信号。 |
| 建筑、设施 | 同功能建筑和单位共用的场景图。记录投影、屋顶与墙面材质、阵营标志、入口方向、落地基线、占地格、屋顶悬挑。 | 放在目标地块上检查地基、朝向、入口、单位遮挡及轮廓。建筑占地由设计和引擎数据给出，画布尺寸单独记录。 |
| 地形、地块 | 同一地形的中心、直边、内外角、转接、坡面、水岸和阴影。记录网格、单格像素、接边类型和相邻规则。 | 按实际网格拼接代表性地图，覆盖重复铺地、内外角及地形过渡，检查漏缝、边界跳色、边缘断裂与高差关系。 |
| 道具、资源、装饰 | 同材质与同用途的资源。记录拾取轮廓、世界缩放、落地点、阴影，按请求加选中、高亮、耗尽或拾取状态。 | 同时摆在常见地面上检查识别度。交互区域对应主体，状态切换时锚点一致。 |
| 按钮 | 同一形状的常态与按下态，必要时补焦点、悬停、禁用图。记录外框、角和边的保留区、中心内容区、图标尺寸及可点击矩形。 | 组装成目标控件后比较各状态，测试最小与较宽尺寸。边角清楚、状态能辨认、点击区域稳定、图标和文字保持对齐。 |
| UI 面板、图标、HUD | 面板、框、进度条底和填充、图标及使用它们的界面截图。记录屏幕空间的色板、层级、描边、字号、对齐、内容边距、拉伸方向和图标网格。 | 在目标分辨率下看文字、数值和图标。检查九宫格或横向拉伸、0/50/100% 填充、交互状态以及与场景的对比。 |
| 特效、投射物 | 同类命中、火焰、尘土、水花等素材。记录触发点、方向、覆盖范围、帧率或时长、循环与色彩用途。 | 以正确位置和事件时序预览。检查透明边、有效区域、与角色动作及场景的叠加。 |

## 确定素材结构

- **世界空间**：以现有网格、单位身高或世界单位建立比例关系。背景、装饰、可交互资源和单位的细节与对比度按其玩法优先级分配。独立 PNG 保留锚点和透明边。多张建成/受损状态固定画布、基线和主要体块。
- **平铺地形**：先列出地图用到的模块与相邻组合，再生成代表块。生成结果需要对齐边缘和实拼核对。把可重复铺设的底层、边缘过渡和点缀分开，有助于保留稳定的拼接关系。
- **屏幕空间**：UI 贴图与布局、文字和点击逻辑分别交付。带间隙的九宫格图集先切出九个区域并按正确顺序拼合，或按引擎支持方式导入。完整皮肤用准确切线保留四角；边和中心按实际需要平铺或拉伸。进度条的底框和填充单独验证。
- **特效**：用场景和对应事件定效果尺寸、颜色与时长。按需求分出投射物、命中和持续效果，记录锚点、帧序与每帧时间。

## 跨类别预览

挑一个能体现玩法的局部场景，用原生或目标游戏缩放放置地形、建筑、人物和道具。覆盖一个重要 UI 操作，例如场景中的补给站与 HUD 上的治疗命令。检查交互意义与层次是否清楚，核对共享的材质色和图形识别点，以及各资产在其所在空间里的尺度和边缘。可用用户提供的截图做合成底图，或在目标引擎中预览。记录实际验证环境。
