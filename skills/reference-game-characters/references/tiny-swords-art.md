# Tiny Swords 整套画风档案

Pixel Frog 的 Tiny Swords 是此档案的参考。已实看本地 Free Pack 的蓝红弓手、蓝红兵营、修道院、塔、矿石、树木、地形图、按钮两态、纸面板、图标、血条和爆炸特效。来源为项目根目录下的 `assets/references/tiny-swords/Tiny Swords (Free Pack)/`。下表文件名相对该目录。另有 [作者资源包说明](https://pixelfrog-assets.itch.io/tiny-swords) 与 [作者 UI 更新说明](https://pixelfrog-assets.itch.io/tiny-swords/devlog/1158927/ui-elements-update)。

## 从整套图提取的共性

- 世界空间用轻俯视呈现角色正侧面、建筑屋顶与正立面，地形顶面、边缘和崖壁有清楚的高差关系。每类资产沿用对应投影。屏幕空间的 UI 使用正面边框和层叠材质。
- 大形先可读。人物有夸张头部和短身，建筑用屋顶、入口、塔身和附属件区分功能，树和矿石靠块面剪影区分资源。先确定整体，再加与用途有关的局部细节。
- 保留硬像素边和成块明暗。单位与交互物常用深色边界强调形体，地形按相邻块与高差处理边缘，建筑和地面不必共用单位描边宽度。
- 颜色按材质与用途分配。自然地面和植被使用不同明度的绿，岩石/墙面用冷灰绿与浅暖色，木面偏暖。单位的肤色、布料和金属各有明暗关系。UI 有浅纸面、深框、装饰金边及有彩控件。
- 同阵营颜色跨资产呼应。实看同造型的蓝红弓手和兵营，单位的服装、盔饰与金属配色会变，兵营屋顶边、门框和装饰色会呼应，石墙与结构仍可识别。新的阵营先规定每类的主色位置与可调材质。

## Enemy Pack 怪物名册观察

- 同一世界视角下，敌怪靠不同的主体形状识别。石甲龟以隆起的硬壳与外伸短肢为主，野猪用低伏拱背、长吻和贴地四足，蜘蛛用鼓起的腹部与放射状细腿，蝙蝠和蜂以翅形与空中姿态为主。大型持棍怪靠宽躯干与武器显示体型差。
- 共同风格来自夸张的大形、清楚的深色边界和成块的材质明暗。壳的石灰绿、野兽的暖棕、蜘蛛的暗紫与飞虫的黄黑各自服务于物种识别。手、脚、爪、翼和头身关系根据对应物种取样。
- 原创敌怪选两个有明确分工的参照。边境哨站的裂石犰狳采用石甲龟的岩甲色阶与野猪的低四足体态，用连续分节甲片、尖吻和卷尾形成新轮廓。用友方单位和建筑核对场景尺度。

## 示例：从医护兵扩展一组同风格素材

项目已制作并检查蓝队医护兵。其圆顶护耳盔和提箱是职业识别点，第一版战锤兵仍是已确认的蓝队人体锚点。以下是新素材任务的编排示例，各项按用户实际需求执行。

| 要做的内容 | 实际输入与生成约束 | 核对方式 |
| --- | --- | --- |
| 前线医护站 | 用蓝队修道院提供建筑材质和阵营色，用蓝队兵营补充低矮入口和构造，用医护兵药箱提供浅色识别标记。做有屋顶、正面入口和基线的小型原创设施。 | 放入目标地图，核对入口相对单位高度、地基占格与屋顶遮挡。 |
| 可拾取医疗包 | 用金矿等地面资源作落地比例和对比度参考，用医护兵药箱作标记参考。生成短轮廓的独立透明图。 | 摆在草地和浅地上检查可辨认度与落地点。 |
| 治疗按钮与面板 | 用大蓝按钮两态学框、中心和亮暗反馈，用原包图标学小尺寸剪影。单独做治疗图标、常态/按下皮肤与面板需要的部件。 | 拼回实际大小，检验窄宽布局、状态切换、图标和文字。 |
| 场景预览 | 用 64×64 地块拼一段道路，把医护站、医护兵和补给包按世界比例放进场景，HUD 显示治疗命令。 | 检查同一职业标记在世界资源与 UI 中的识别，以及整套色彩和层次。 |

需要追加敌怪时，先用同类型敌怪原图或作者预览建立类别规则。例如新掠夺者要从地面剪影、武器与攻击信号上同蓝队区分，并在医疗站场景中核对威胁尺度。
