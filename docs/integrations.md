## 模型和 MCP

视频模型可以替换。用首帧模式提交同一张合图及逐格提示词，保持画面比例和格位，关闭自动运镜；拿到成片后再本地处理。本项目的 Wan 客户端是可选适配器，参数以 [Alibaba Cloud 官方文档](https://www.alibabacloud.com/help/en/model-studio/wan3-video-generation-api-reference/)和工作区为准。

已有图像或视频 MCP 时，可由它完成生图或提交视频任务，保留下载到本地的原始 PNG／MP4。工具的入参、上传方式、模型名、任务状态和用量由提供方决定。合图与拆帧接口保持相同；本项目没有安装或注册独立 MCP 服务，也不要求使用某个 Agent 或客户端。

## SpriteFrame「逐帧」

有 SpriteFrame 工作台时，在素材区选择「导入格位 JSON」，再打开同批 MP4。查看网格与背景色，按 10 fps 提取后使用挑帧编辑器，或先按动作挑一段再抽样。武器或粒子容易被自动识别框切掉，建议使用整格裁框或先扫描完整动作范围。这里自带 CLI 和真实成片，可独立复现导出。

## 格位格式 v1

`width` 与 `height` 是**首帧**像素尺寸；`cols` 与 `rows` 定义整张图；`color` 是六位十六进制抠像色；`baseline` 是单格高度内 0–1 的脚底线。每个 `cells[]` 项的 `row`、`col` 从 0 开始，`name` 用于展示，可选 `action` 覆盖全局动作标签。支持 `idle`、`walk`、`run`、`attack` 和 `vfx`；独立特效不写脚底锚点。

导出使用实际视频宽高，列边界为 `roundHalfUp(col × 视频宽 / cols)`，行边界同理，相邻格共用边界。裁框元数据为 `[x,y,width,height]`；脚底锚点相对于每格 PNG 左上角。CLI 要求成片与参考图宽高比误差在 1% 内，并使用方形像素；有黑边、旋转或构图漂移时先修正输入。生成的目录按行列和动作命名，`manifest.json` 保留角色名。

## 导入游戏前

- 用 `--start` / `--end` 选时间段；`--fps` 是统一采样频率。先看源视频的完整帧率，避免抽样跳过脱手、触地等动作瞬间。
- `--tolerance` 默认 48，以像素和背景色的最大 RGB 通道差为阈值。残边增多时先检查底色，角色或特效被吃掉时调低阈值或重新选底色。每组的 `empty_frames` 和 `edge_frames` 是自动提示，未列出的帧也需要审核。
- 抽出的 PNG 保留固定格位和原始视频像素尺度。确认角色身份、脚底、装备和透明边，再挑循环帧或单次动作帧。若缩放请用最近邻；投射物、命中特效和角色各自输出，按游戏事件同步。
