# First release checklist

[简体中文](release.md) · [Project home](../README.md)

- Check the [MIT License](../LICENSE) for code and documentation, the [CC0 1.0 dedication](../LICENSE-CC0) for original assets and the [scope in NOTICE](../NOTICE.en.md). Review the provenance of new assets before updating the notice.
- Review the files intended for release for original pack assets, reference-derived images, private configuration and temporary archives. Git still tracks files that were added before an ignore rule. Run the README commands from a clean checkout and verify that the sample PNG, MP4 and layout JSON are included. [Local example](../README.md#reproduce-the-example-offline)
- Wait for CI to pass before creating a public release. Update the project links when the public repository and release URLs are available. Verify public access while signed out.
