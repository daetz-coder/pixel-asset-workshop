# Sources and distribution

[简体中文](NOTICE.md) · [Project home](README.en.md)

- Pixel Frog made **Tiny Swords**. The author allows use and modification of the current Free Pack in personal and commercial projects and restricts redistribution, resale and repackaging of those assets, including modified assets. The author's separately listed older release has different terms. [Tiny Swords author page](https://pixelfrog-assets.itch.io/tiny-swords)
- The source pack, user-supplied reference art, cropped source frames and comparisons containing source frames are local working materials. The repository ignores `assets/references/tiny-swords/` and `work/`. To reproduce a comparison, obtain the pack and run the commands locally. [Tiny Swords comparison](examples/tiny-swords/README.en.md#comparison-with-the-original)
- The example roster, frontier outpost and their previews use generated assets from this project. The six-unit workflow poster and export record come from the same batch in the companion SpriteFrame workspace, using the same original characters and video. This notice documents provenance. Confirm the licensing terms for code and media before a public release. [First release checklist](docs/release.en.md)
- Wan3.0 Video Prime is an optional service from Alibaba Cloud Model Studio. The local workflow requires no model weights, provider account or service credentials.
