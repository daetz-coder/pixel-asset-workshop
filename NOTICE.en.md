# Sources and distribution

[简体中文](NOTICE.md) · [Project home](README.md)

- Pixel Frog made **Tiny Swords**. The author allows use and modification of the current Free Pack in personal and commercial projects and restricts redistribution, resale and repackaging of those assets, including modified assets. The author's separately listed older release has different terms. [Tiny Swords author page](https://pixelfrog-assets.itch.io/tiny-swords)
- The source pack, user-supplied reference art, cropped source frames and comparisons containing source frames are local working materials. The repository ignores `assets/references/tiny-swords/` and `work/`. To reproduce a comparison, obtain the pack and run the commands locally. [Tiny Swords comparison](examples/tiny-swords/README.md#comparison-with-the-original)
- The example roster, frontier outpost and their previews use generated assets from this project. The English SpriteFrame screenshots and export record use the six-unit batch. The Godot playback capture uses the extracted generated sprites. The comparison that includes Pixel Frog’s artwork is generated locally. This notice documents provenance. Confirm the licensing terms for code and media before a public release. [First release checklist](docs/release.en.md)
- Wan3.0 Video Prime is an optional service from Alibaba Cloud Model Studio. The local workflow requires no model weights, provider account or service credentials.
